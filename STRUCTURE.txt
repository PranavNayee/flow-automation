MODULES OVERVIEW
================

1. queue_manager.py
   - SQLite-based job queue
   - States: pending, running, completed, failed, retry
   - Resume-safe: crashed jobs auto-reset
   - Import from CSV/JSON

2. flow_driver.py
   - Playwright automation for Flow
   - Persistent browser profile (login once)
   - Human-like typing and delays
   - Screenshot on every error
   - CAPTCHA/warning detection

3. downloader.py
   - Downloads generated videos
   - Multiple methods: URL, link, button
   - Resumes interrupted downloads
   - Renames by scene_id

4. health_check.py
   - Validates UI selectors before run
   - Auto-generates update guide if broken
   - Essential vs. optional selector checks
   - Warning detection (CAPTCHA, rate limits)

5. credit_tracker.py
   - Tracks monthly generation usage
   - Enforces credit limits
   - Persists across sessions
   - Monthly rollover handling

6. editor.py
   - FFmpeg video stitching
   - Add background music
   - Burn subtitles
   - Video metadata extraction

7. script_writer.py
   - OpenAI or Anthropic LLM
   - Generate scene prompts from topics
   - Refine prompts with feedback
   - Configurable style and length

8. dashboard.py
   - Streamlit real-time monitoring
   - Queue visualization
   - Video preview
   - Approve/reject workflow

9. uploader.py
   - YouTube Data API v3
   - OAuth authentication
   - Automatic AI content disclosure flag
   - Upload quota tracking

SAFETY FEATURES
===============

✓ Rate limiting (hourly + daily)
✓ Credit tracking & limits

✓ CAPTCHA detection & stop
✓ Warning detection & stop

CONFIGURATION FILES
===================

config.yaml
- Video settings (aspect ratio, quality)
- Editor settings (codec, CRF)
- LLM settings (provider, model)
- YouTube upload defaults

selectors.yaml ⚠️ UPDATE WHEN FLOW UI CHANGES
- All UI element selectors
- Timeouts and wait durations
- Organized by page section
- Comment with last verified date

.env (from .env.example)
- Rate limits (MAX_GENERATIONS_PER_HOUR, etc.)
- API keys (OPENAI_API_KEY, etc.)
- Paths (BROWSER_PROFILE_PATH, DATABASE_PATH)
- Safety settings

WORKFLOW
========

1. Prepare Prompts
   CSV/JSON → import_prompts.py → SQLite queue

2. Run Automation
   run_automation.py:
   - Health check selectors
   - For each pending job:
     * Navigate to Flow
     * Check warnings
     * Enter prompt
     * Generate video
     * Download file
     * Apply rate limits
   - Resume-safe (crash recovery)

3. Monitor Progress
   streamlit run src/dashboard.py
   - Real-time status
   - Video previews
   - Queue management

4. Edit Videos (optional)
   editor.py:
   - Stitch scenes
   - Add audio/subtitles
   - Export final video

5. Upload to YouTube (optional)
   uploader.py:
   - OAuth authentication
   - AI disclosure flag (automatic)
   - Upload with metadata

⚠️ BEFORE FIRST RUN
====================

1. Open Flow in browser: https://labs.google/flow
2. Inspect UI with DevTools (F12)
3. Verify/update these selectors in selectors.yaml:
   - main.prompt_textarea
   - main.prompt_submit_button
   - main.generating_indicator
   - main.generation_complete
   - main.download_button
4. Update "Last verified" date in selectors.yaml
5. Start with 1 test job
6. Monitor the entire first generation
